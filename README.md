# Z85snip

Инженерный калькулятор расчётов КОС по СНиП-85 (без «уровнем выше»).

## Быстрый старт
- Создайте venv
- Установите зависимости
- Запустите UI (Qt) или расчётные сценарии

Структура:
- src/z85snip/core      — базовые утилиты, валидация, единицы измерения, ошибки
- src/z85snip/snip85    — формулы/методики СНиП-85 (как библиотека)
- src/z85snip/domain    — доменная модель: сооружения, связи, параметры
- src/z85snip/application — сценарии/оркестрация расчётов
- src/z85snip/ui/qt     — интерфейс PySide6 + (опционально) QtWebEngine для LaTeX
- tests                — тесты (Pytest)
