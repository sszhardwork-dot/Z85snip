# Входные данные и единицы измерения

Эта таблица фиксирует контракт на исходные параметры, используемые в расчетах по СНиП-85. Все значения должны передаваться в указанных единицах и диапазонах; источник подсказывает, берется ли величина из пользовательского ввода или вычисляется в процессе.

| Параметр | Обозначение СНиП | Единицы | Диапазон | Источник |
| --- | --- | --- | --- | --- |
| Расход минимальный | Qmin | м³/сут | > 0 | ввод пользователя |
| Расход средний | Qavg | м³/сут | > 0 | ввод пользователя |
| Расход максимальный | Qmax | м³/сут | > 0 | ввод пользователя |
| Коэффициент неравномерности/усреднения | K | безразмерный | > 0 | ввод пользователя или snip85_library |
| Требуемый объем усреднителя | W_req | м³ | > 0 | рассчитывается (hydraulics.equalization_volume) |
| Фактический объем | W_fact | м³ | > 0 | рассчитывается (геометрия) |
| Время усреднения | t_averaging | ч | > 0 | ввод пользователя |
| Время пребывания в аэротенке | t_at | ч | > 0 | рассчитывается (aeration.total_aeration_time) |
| Время регенерации | t_r | ч | > 0 | рассчитывается (aeration.regeneration_time) |
| Время окисления | t_o | ч | > 0 | рассчитывается (aeration.oxidation_time) |
| Смешанная БПК | L_mix | мг/л | > 0 | рассчитывается (recirculation.mix_concentration) |
| Коэффициент рециркуляции | R_i | безразмерный | 0..1 | ввод пользователя или snip85_library |
| Удельная скорость окисления | ρ | мг/(л·ч) | > 0 | snip85_library |
| Поверхностная нагрузка | q_s | м³/(м²·сут) | > 0 | snip85_library |
| Площадь отстойника | F | м² | > 0 | рассчитывается (hydraulics.surface_loading_area) |

Все формулы в слое ``snip85`` документируют ожидаемые единицы входов и выходов в docstring, а валидаторы из ``z85snip.core.validation`` предотвращают расчет с некорректными диапазонами.
