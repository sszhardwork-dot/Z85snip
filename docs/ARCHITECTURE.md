# Архитектура

Принципы:
- Математика строго по СНиП-85 (без усложнений «уровнем выше»).
- UI отделён от расчётов.
- Доменная модель и формулы тестируются.

Пакеты:
- core: ошибки, валидация, единицы, служебные типы
- snip85: формулы и методики
- domain: сооружения, параметры, связи
- application: сценарии расчёта и пайплайны
- ui: интерфейс
